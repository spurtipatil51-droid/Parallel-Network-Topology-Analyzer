Parallel Network Topology Analyzer

About the Project

This project is developed using Python to analyze a random computer network and compare sequential and parallel processing.

Objectives

- Generate a random computer network.
- Identify isolated nodes.
- Calculate clustering coefficients.
- Compare sequential and parallel execution times.
- Visualize network topology and performance.

Technologies Used

- Python
- NetworkX
- Matplotlib
- Multiprocessing

How to Run

1. Install the required libraries:
   "pip install -r requirements.txt"
2. Run the program:
   "python network_analyzer.py"

Output

The project displays network information, clustering coefficients, execution times, speedup, and graphical comparisons.
